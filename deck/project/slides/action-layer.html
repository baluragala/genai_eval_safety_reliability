The action layer

Check every action against the system of record

Before issue_refund runs

  • The order was looked up in this conversation
  • It belongs to the authenticated customer
  • Delivered within 30 days, not final sale
  • Amount equals the order total, from the database
  • Not already refunded
  • Over $500 goes to a human

And the rest

  • Least privilege: no calculator for a support bot
  • Sandbox: arithmetic-only AST, not eval
  • Egress: email only the customer on file
  • Memory: preferences, never entitlements

Reference implementations: agentlab.guards (RefundPolicy, EgressPolicy, MemoryWriteGuard, SafeCalculator)

The key idea is grounding. The refund amount comes from the database, not from anything the model or the customer said. That single check defeats ATK-01, ATK-03 and ATK-04 regardless of how persuasive the injected text is. A real sandbox goes further, with containers or micro-VMs, no network and resource limits.
