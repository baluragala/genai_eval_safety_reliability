Block 4 · Guardrails · Notebook 04

Defence in depth: five layers, one of them carries the load

Input

Regex screen, LLM injection classifier: catches the obvious

Context

Spotlighting: wrap untrusted content, mark it as data

Action

Allowlist, sandbox, refund policy, egress, memory rules. Holds even when the model is fooled

Oversight

Approval gate: a human signs off on high-impact actions

Output

Redact secrets and other customers' data from replies

In Notebook 04 learners add these one layer at a time and re-run the red team after each, watching the scoreboard. Show the regex bypass: a polite rewrite of ATK-01 with no trigger phrases. Input filters are whack-a-mole. Spotlighting reduces risk but the model can still choose to follow the text. The action layer checks every side-effecting call against the system of record, so it doesn't depend on what the model believes.
