LLM-as-judge

The judge is a model too, so evaluate it

The reply

"Great news, your refund of $210.00 for A-1008 has been processed!"

The trace

issue_refund(A-1008, 210.0)
→ state: GW_DECLINED, refund_id: null

Judge hygiene

  • Give it the evidence: the trace, not only the reply
  • A fixed rubric with anchored 1–5 scores, returned as JSON
  • Calibrate against trusted labels: agreement, Cohen's κ
  • Watch false passes: bad runs it approves
  • Re-calibrate whenever you change the judge
This example is gallery trace E from Notebook 02, which was constructed by hand. A judge that sees only the reply has no way to know the refund failed; the text reads perfectly. In the notebook, the same judge grades every case twice, reply-only and with the trace, and both are compared against the oracle. Let the live numbers speak. The false-pass count is the one to watch, because a false pass means a bad run approved.
