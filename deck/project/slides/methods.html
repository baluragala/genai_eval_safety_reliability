Methods

Three ways to evaluate, each catching what the others miss

Trace-based

Assert on how the agent got there: lookup before refund, policy checked, no loops. Catches right answers reached for the wrong reasons.

LLM-as-judge

A second model grades against a rubric and returns JSON. Good for tone, clarity and honesty. It needs calibrating before you trust it.

Simulation

Perturbed tickets and LLM-played customers over several turns. Adds the variety real customers bring that ten hand-written cases can't.

These map to sections 4, 5 and 6 of Notebook 01. Trace-based checks are cheap and deterministic, so run them on every change. The judge costs a model call per case and is itself fallible. Simulation is where you find the tickets nobody thought to write: typos, Hinglish, a customer who only gives the order ID when asked.
