Operational controls

Controls operators can use without a deploy

Audit log

Append-only and hash-chained. Edit one past entry and every hash after it breaks.

Kill switch

Disable refunds, or all writes, in production. The agent degrades to escalating.

Release gate

Ship only if success ≥ 0.9, zero attacks breached, chaos ≥ 0.8, cost and p95 in budget.

The release gate in Notebook 06 scores the baseline agent and the hardened agent on the same six metrics: success rate, tool correctness, attack success rate, chaos success rate, cost per task and p95 latency. The thresholds are in agentlab/oversight.py. Put this gate in CI so a prompt change that breaks safety fails the build the same way a failing unit test would.
