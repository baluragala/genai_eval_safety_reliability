Open the floor. Questions that usually come up: how to build a golden set when there is no clear oracle (use human labels, then calibrate a judge against them); whether guardrails belong in the agent framework or a gateway (both; action checks sit closest to the tool); and how to monitor in production (sample traces, run detectors and the judge offline, alert on guard-event rates).
