Consistency

pass@k asks "ever?". pass^k asks "every time?"

pass@k

Chance that at least one of k tries succeeds. Fits code generation, where you keep the best attempt.

pass^k

Chance that all k tries succeed. Fits agents that act for real customers: they need it right every time.

Worked example: 3 of 4 runs succeed →

pass@2 = 1.00

pass^2 = 0.50

pass^4 = 0.00

The worked example is pure arithmetic: pass^2 is C(3,2)/C(4,2) = 3/6. The same 75% single-run success looks perfect as pass@2 and fails outright as pass^4. In the notebook we run T02 and T03 four times at temperature 1.0 and compute both. Temperature 0 hides this variance, but production systems often run hotter, and customers retry.
