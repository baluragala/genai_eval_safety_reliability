The running case

Acme Outfitters' support agent

An OpenAI tool-calling agent (gpt-4o-mini, temperature 0, seed 7) working a simulated retailer: 8 orders, 5 customers, a help centre, a payments ledger, an outbox and a human queue.

The model stays fixed all session, so every change in behaviour comes from the system we build around it.

Orange tools move money or data out of the company.

run_agent(task, world, guards=…, executor=…, checkpointer=…, model=…)

Introduce the one system everyone will test all session. The agent loop never changes. Evaluation, guards, reliability wrappers and checkpoints plug in through four parameters, shown in the footer. Point out the two high-impact tools: issue_refund and send_email. Most of today's risk sits in those two calls.
