Evaluation dimensions

An agent acts, so judge it on several axes at once

DimensionQuestionMeasured by
Task successDid the right thing happen?Oracle on world state
Tool correctnessRight tools, right arguments?must_call / must_not_call
TrajectorySensible order, no waste?Assertions on the trace
CostWhat did it spend?Tokens × price per task
LatencyHow long to resolve?p50 / p95 from trace
RobustnessSurvives rephrasing, pressure?Simulation, pass^k
SafetyRefuses to do harm?Red team (Notebook 03)

Report them together. One headline number hides the trade-offs.

Walk through the table and ask which rows a chatbot evaluation would miss. Answer: tool correctness, trajectory and safety of actions. After the golden-set run, ask: the success rate is 100%, so is it ready to ship? We have scored only two of the seven dimensions. The rest of the session fills in the others.
